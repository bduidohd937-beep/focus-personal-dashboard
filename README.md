# FOCUS — Personal Dashboard V2.3

개인용 공부 루틴·집중 타이머·시험 D-Day·통계를 PC와 갤럭시에서 사용하는 PWA입니다.

운영 주소: https://focus-personal-dashboard.vercel.app

## 이미 구현된 기능
- 매일·주간 루틴 체크, 캘린더, 루틴 달성률, 집중 시간 통계
- 홈에서 과목 선택 후 즉시 집중 시작, 타이머 시작·일시정지·재시작·저장
- 시험 D-Day, 하루 집중 목표, 4가지 테마
- Supabase 이메일 계정, PC·갤럭시 동기화, JSON 내보내기 및 복원
- 오프라인 로컬 기록, 복구 후 동기화, 버전 충돌 감지

## V2.3 — UI/UX와 운영 안정성
1. **동기화 충돌 비교**: 설정에서 기기/클라우드의 서로 다른 루틴·체크·집중 기록·개인화 설정을 나란히 확인하고 어느 전체 기록을 적용할지 선택합니다. 선택 전 백업을 권장합니다. 충돌 없는 수정은 기존처럼 자동 병합합니다.
2. **통합 홈**: 홈에서 과목을 정하고 곧바로 집중 타이머로 이동합니다. 오늘 체크리스트·목표·집중 시간을 한 화면에서 확인합니다.
3. **모바일**: 누르기 영역, 좁은 화면에서의 레이아웃, 동기화 상태 표시를 정리했습니다.
4. **타이머 보호**: 먼저 공부 세션을 안전하게 저장한 뒤 타이머를 초기화합니다. 저장 실패 시 타이머 보존. 저장 세션은 시작한 날짜(Asia/Seoul)에 귀속됩니다. 일시정지 시간은 제외됩니다. 1회 최대 12시간입니다.
5. **품질 체계**: GitHub Actions에서 JS 구문 검사·단위 테스트·Playwright 브라우저 테스트 및 오프라인 캐시 점검을 실행합니다. Vercel이 정식 운영 배포이며 설정되지 않은 GitHub Pages는 수동 실행만 유지합니다.

## 보안 및 기록 보호
- 기록은 브라우저 localStorage에 즉시 보관되고, 로그인하면 Supabase의 사용자별 RLS 테이블에 동기화됩니다.
- 클라우드 기록이 변경될 때 백업용 로컬 보호본을 최대 5개 유지하며, 설정에서 최신 보호본을 JSON으로 다운로드할 수 있습니다. 브라우저 데이터 삭제 시 로컬 보호본도 사라지므로 파일 다운로드를 권장합니다.
- 동기화는 완전한 실시간 소켓 방식이 아니라 약 20초 간격 및 포커스/연결 이벤트로 확인합니다.
- 개인정보는 종단간 암호화(E2EE) 방식으로 처리되지 않습니다. 비밀번호나 서비스 역할 키를 소스코드에 저장하지 않습니다. 공개용 Supabase publishable key만 클라이언트에 사용합니다.
- 브라우저 캐시 저장 용량과 기기별 백그라운드 제한은 OS에 따라 다릅니다.

## 개발 및 검증
- Node.js 22+: `npm test` — 데이터·병합·타이머 순수 로직 검사
- 브라우저 테스트(Playwright 설치 후): `node tests/browser.mjs` — 홈, 집중 저장, 개인화, 새로고침, 오프라인 캐시
- GitHub Actions: `.github/workflows/test.yml`
- 정식 배포: 기존 Vercel 프로젝트 `focus-personal-dashboard`.
- Supabase 이메일 인증 리다이렉트 URL은 `https://focus-personal-dashboard.vercel.app/**`를 허용해야 합니다.

기존 V1 로컬 데이터 키 `focus.personal.v1`과 클라우드 동기화 테이블을 그대로 사용하며, 저장 형식은 `version:1`로 유지됩니다. 업데이트 시 기존 기록을 초기화하지 않습니다.
